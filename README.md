# Happy Birthday Bhumi

A single-page birthday greeting card for Bhumi, featuring her photo, a birthday message, and an "Open Surprise" button.

## Technologies
- Plain HTML, CSS, and JavaScript (no build step)
- Netlify Image CDN to serve an optimized WebP version of the photo

## Run locally
```bash
netlify dev
```
Then open the printed local URL. (Opening `index.html` directly works too, but the photo is served through the Netlify Image CDN, so it appears only when running via Netlify.)
